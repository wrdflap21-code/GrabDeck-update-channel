# GrabDeck — canal de atualizações

Este repositório público contém apenas pacotes de atualização **criptografados e assinados**, instalados por cópias do GrabDeck entregues privadamente pelo proprietário.

Não contém o instalador completo, código-fonte do aplicativo, credenciais GitHub, chaves de descriptografia ou chave privada de assinatura. Os arquivos source code ZIP/TAR gerados automaticamente pelo GitHub referem-se somente ao README deste repositório.

Os arquivos `.gdup` não são ZIPs para extração manual. O aplicativo verifica a assinatura do manifesto, a integridade do pacote e os arquivos antes de instalar. Mantenha suas configurações e histórico na pasta `dados`.

Não solicite nem publique chaves neste repositório. Quem receber uma cópia autorizada do app pode repassá-la; este canal não é um sistema de licença individual ou proteção contra cópia.
